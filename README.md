# TAREA-1.--MCP-Y-SISTEMA-DE-ARCHIVOS-INVESTIGACI-N-E-IMPLEMENTACI-N
Comprender cómo un modelo de lenguaje pasa de estar aislado a poder operar sobre archivos locales, distinguir con precisión el Model Context Protocol (MCP) de una API tradicional, e implementar, verificar y documentar la instalación de un servidor MCP de sistema de archivos en un cliente real.
